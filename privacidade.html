5. Com quem compartilhamos

  • Ademicon Administradora de Consórcios, para analisar e formalizar a sua adesão e administrar a sua cota. A partir daí, a Ademicon também trata os seus dados de acordo com a política de privacidade dela.
  • Prestadores de serviço que nos ajudam a operar: Supabase (banco de dados onde ficam os contatos recebidos pelos formulários, os cadastros e a nossa ferramenta interna de acompanhamento de clientes, com servidores em São Paulo), GitHub (hospedagem dos sites), Google (serviço de fontes e planilha usada apenas como reserva, se o banco de dados estiver indisponível) e Meta (WhatsApp). Eles tratam os dados apenas para prestar o serviço contratado.
  • Autoridades, quando houver obrigação legal ou ordem judicial.

Não vendemos nem alugamos seus dados pessoais.

6. Transferência para outros países

Alguns desses prestadores (como Google, GitHub e Meta) podem armazenar ou processar dados fora do Brasil. Nesses casos, a transferência segue as hipóteses permitidas pela LGPD (art. 33).

7. Por quanto tempo guardamos

  • Dados de quem é cliente: enquanto durar a sua cota e, depois, pelo prazo necessário para cumprir obrigações legais e para a defesa de direitos.
  • Dados de quem preencheu o formulário de consultoria e não se tornou cliente: 24 meses contados do último contato, ou até você pedir a exclusão, o que ocorrer primeiro.

Depois desses prazos, os dados são excluídos ou anonimizados.

8. Como protegemos

Os sites usam conexão criptografada (HTTPS). Os dados enviados pelos formulários vão direto para um banco de dados que não pode ser lido pelo site: só consultores autorizados, com login, acessam os contatos, e cada consultor vê apenas os atendimentos sob sua responsabilidade.

9. Seus direitos

Pela LGPD (art. 18), você pode pedir, a qualquer momento:

  • confirmação de que tratamos seus dados e acesso a eles;
  • correção de dados incompletos, inexatos ou desatualizados;
  • anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desacordo com a lei;
  • portabilidade dos dados a outro fornecedor;
  • eliminação dos dados tratados com base no seu consentimento;
  • informação sobre com quem compartilhamos seus dados;
  • informação sobre a possibilidade de não dar consentimento e as consequências disso;
  • revogação do consentimento.
